# Grupo 02 - Estimación de Gastos Médicos (Streamlit)

Este proyecto está diseñado para ser desarrollado e iterado mediante la CLI de Antigravity utilizando servidores MCP.

## Instrucciones de Inicio
1. Clona el repositorio/descomprime este ZIP.
2. Inicia Antigravity CLI limitando el alcance del servidor MCP al directorio actual (`workspace/`).
3. Proporciona el archivo `agents.md` como system prompt para que los agentes comiencen a desarrollar la solución en orden secuencial (Data -> ML -> Frontend).
